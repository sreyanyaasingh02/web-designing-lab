# Experiment 5: Weather App

## Aim
To create a Weather App using the Fetch API or Axios that fetches real-time weather data based on user input.

## Description
This project is a web-based Weather App that allows users to enter a city name and retrieve its current weather information using a weather API.

The application demonstrates how JavaScript can communicate with external APIs and display dynamically fetched data on a webpage.

## Objectives
- To understand how APIs work.
- To fetch real-time weather data using JavaScript.
- To learn how to use the Fetch API or Axios.
- To handle user input and display dynamic results.
- To understand basic error handling while working with API requests.

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API or Axios
- Weather API

## Working
1. The user enters a city name.
2. The application sends a request to the weather API.
3. The API returns weather information for the requested city.
4. JavaScript processes the response.
5. The weather information is displayed on the webpage.

## Learning Outcomes
After completing this experiment, I learned:
- How to fetch data from an external API.
- How to work with asynchronous JavaScript.
- How to process API responses.
- How to handle user input and display dynamic content.
- How to build an interactive web application.

## Conclusion
The Weather App demonstrates the use of JavaScript and external APIs to fetch and display real-time weather information based on user input.
