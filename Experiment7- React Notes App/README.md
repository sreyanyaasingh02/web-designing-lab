# Experiment 7 - React Notes App

## Aim
To develop a single-page application using React.js that allows users to add, view, update and delete notes.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Features
- Add new notes with a title and description.
- View all saved notes.
- Edit existing notes.
- Delete unwanted notes.
- Store notes in the browser using Local Storage.
- Responsive layout for smaller screens.

## Description
This project is a simple Notes App created using React.js. It provides a form to enter a note title and description. Users can add notes, edit them whenever needed and delete them.

The application uses React state to manage the notes and Local Storage to save them in the browser.

## Learning Outcomes
- Learned the basics of React components and JSX.
- Used the useState and useEffect hooks.
- Practised handling form inputs and button events.
- Understood how to save data using Local Storage.

## Conclusion
The React Notes App was successfully developed. It allows users to manage their notes through a simple and easy-to-use interface.
