
# Experiment 1: GitHub Repository Setup

## Aim
To set up a GitHub repository for a web development project, create branches, merge changes, and use GitHub Pages to host a simple static website.

## Objectives
- Understand Git and GitHub.
- Create and manage a GitHub repository.
- Learn how to create branches.
- Make commits and push changes.
- Understand merging and version control.
- Deploy a static website using GitHub Pages.

## Tools Used
- Visual Studio Code
- Git
- GitHub
- HTML
- CSS

## Procedure
1. Created a public GitHub repository named `01-github-repository`.
2. Cloned the repository to the local computer.
3. Opened the project in Visual Studio Code.
4. Created a new branch named `experiment-1`.

## Branch Information
- Main branch: `main`
- Working branch: `experiment-1`

## Learning Outcomes
- Learned how to create a GitHub repository.
- Understood the process of cloning a repository.
- Learned basic Git branch management.

## Conclusion
Successfully created a GitHub repository, cloned it locally, and created a separate working branch for Experiment 1.
