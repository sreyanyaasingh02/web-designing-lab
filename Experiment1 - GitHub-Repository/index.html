Experiment 1: GitHub Repository Setup

Web Designing Lab | Second Year

Aim Objectives Tools Procedure Outcome

1. Aim

To create and manage a GitHub repository, understand branching and merging, and deploy a simple static website using GitHub Pages.

2. Objectives

  • Understand Git and GitHub.
  • Create and clone a repository.
  • Create and manage Git branches.
  • Learn commits, pushing and merging.
  • Deploy a website using GitHub Pages.

3. Tools and Technologies Used

  • Visual Studio Code
  • Git
  • GitHub
  • HTML5
  • CSS3

4. Procedure

  1. Created a public GitHub repository.
  2. Cloned the repository into VS Code.
  3. Created a branch named experiment-1.
  4. Updated the README documentation.
  5. Staged and committed the changes.
  6. Pushed the branch to GitHub.
  7. Created and merged a Pull Request.
  8. Created an HTML webpage.
  9. Enabled GitHub Pages for deployment.

5. Learning Outcomes

Successfully learned repository creation, cloning, branching, committing, pushing, merging and website deployment using Git and GitHub.
