# Experiment 2: Personal Portfolio Website
## Aim
To design and develop a personal portfolio website using HTML and CSS.

## Description
This project is a responsive personal portfolio website created to introduce my academic background, technical skills, projects, and learning journey as a Computer Science student.

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and layout
- Unsplash – Background images

## Website Sections
1. Home – Introduction and welcome section
2. About Me – Academic profile and interests
3. Skills – Technical skills
4. Projects – Mini-project showcase
5. What I'm Learning – Current learning goals
6. Contact – Contact and GitHub information

## Features
- Navigation menu
- Background images
- Styled sections and project cards
- Responsive layout for smaller screens

## How to Run
1. Download or clone this repository.
2. Open the `Experiment-2-Portfolio` folder.
3. Open `index.html` in a web browser.

## Learning Outcomes
- Understanding HTML page structure
- Applying CSS styling and layouts
- Using background images
- Creating navigation links
- Building a basic responsive portfolio
