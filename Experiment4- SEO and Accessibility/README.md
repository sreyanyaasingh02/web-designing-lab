
# Experiment 4: SEO and Accessibility

## Aim
To optimize a webpage for Search Engine Optimization (SEO) and accessibility using semantic HTML, proper heading structure, and meta tags.

## Objectives
- To understand the importance of SEO.
- To use semantic HTML elements.
- To arrange headings in a proper order.
- To add suitable title and meta description tags.
- To improve accessibility for keyboard users.

## Tools Used
- Visual Studio Code
- HTML5
- CSS3
- Web Browser

## Description
A simple Home Gardening webpage was created to demonstrate basic SEO and accessibility techniques. The page contains information about gardening, plant care, and its benefits.

## Features Implemented
1. Added a descriptive page title and meta description.
2. Used semantic HTML elements such as header, nav, main, section, article, and footer.
3. Maintained a proper heading structure.
4. Added a skip-to-content link.
5. Added keyboard focus styling for navigation links.
6. Used simple CSS styling and a gardening background image.

## Learning Outcomes
- Learned how to structure a webpage using semantic HTML.
- Understood the role of meta tags in SEO.
- Learned the importance of accessible navigation.
- Improved knowledge of HTML and CSS.

## Conclusion
This experiment helped me understand how SEO and accessibility can improve a webpage. Semantic HTML, proper headings, and meta tags make website content easier to understand for both users and search engines.
