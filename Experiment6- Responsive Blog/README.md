# Experiment 6 - Responsive Shoe Blog

## Aim
To build a responsive blog website using Bootstrap and CSS media queries that adapts to different screen sizes.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Media Queries
- Visual Studio Code

## About the Project
Shoe Stories is a simple blog website that displays different varieties of shoes. It includes information about sneakers, formal shoes, sports shoes and boots, along with their estimated price ranges.

## Features
- Navigation bar with Home, Shoe Collection and About links
- Header section with a background image
- Owner name displayed below the main heading
- Four shoe varieties with images and descriptions
- Estimated price ranges for each shoe type
- Responsive shoe cards using Bootstrap
- CSS media queries for mobile and tablet screens
- About section and footer

## Responsive Design
Bootstrap grid classes are used to arrange the shoe cards according to screen size. CSS media queries adjust the layout and text sizes for tablets and mobile phones.

## Learning Outcomes
- Learned how to use Bootstrap in a webpage.
- Understood the Bootstrap grid system.
- Learned to use CSS media queries.
- Practised creating responsive layouts.
- Learned how to add images and style content cards.

## Conclusion
This experiment helped me understand responsive web design using Bootstrap and CSS media queries. The website adjusts to different screen sizes while displaying information about different types of shoes.
